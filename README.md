# Clarify

Clarify is a full-stack TypeScript app that records lectures and helps users understand them better through AI insights.

Built with Expo, Express, and AI it captures audio, transcribes it, and generates summaries, key points, and topic insights.

## Stack

- **Frontend:** Expo (React Native, TypeScript)
- **Backend:** Express (TypeScript)
- **AI:** OpenAI API
